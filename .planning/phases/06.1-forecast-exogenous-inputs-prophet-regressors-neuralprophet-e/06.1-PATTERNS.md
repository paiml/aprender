## Pattern Assignments

### `regressors.rs` — Prophet external regressors (service, transform)

**Analog:** `.claude/skills/spike-findings-aprender/sources/011-prophet-regressor-parity/src/regressors.rs`
(full-parity prototype) spliced onto `crates/aprender-forecast/src/prophet.rs`.

**Imports pattern** — the prototype imports the SHIPPED types; the in-crate port becomes
`use crate::prophet::{...}`:
```rust
use aprender_forecast::prophet::{
    feature_row, holiday_day_sets, Column, Design, Mode, Model, Params,
};
```

**Standardisation pattern (the ddof trap, D-23):** `regressors.rs::standardize_one` —
history rows only, `auto` = "do not standardise a column whose unique values are exactly {0,1}",
variance divided by `(n - 1.0)`:
```rust
let do_std = spec.standardize.unwrap_or(!binary);
let (mu, std) = if do_std {
    let n = history.len() as f64;
    let mu = history.iter().sum::<f64>() / n;
    let var = history.iter().map(|v| (v - mu) * (v - mu)).sum::<f64>() / (n - 1.0); // ddof = 1
    (mu, var.sqrt())
} else { (0.0, 1.0) };
```

**Splice pattern (append-only; this is what makes D-19 free):** `regressors.rs::splice` —
rebuild `x` at `new_k` width copying the base row prefix, then push one entry each onto
`cols` / `prior_scales` / `s_a` / `s_m`. No existing column index moves; the optimiser and
gradient are untouched:
```rust
x[i * new_k..i * new_k + base_k].copy_from_slice(&d.x[i * base_k..(i + 1) * base_k]);
x[i * new_k + base_k + j] = (values_history[j][i] - reg.mu) / reg.std;
...
d.s_a.push(if reg.mode == Mode::Additive { 1.0 } else { 0.0 });
d.s_m.push(if reg.mode == Mode::Multiplicative { 1.0 } else { 0.0 });
d.x = x; d.k = new_k;
```

**Column-order pattern to preserve** — `prophet.rs:127-166 columns()`: seasonalities in
insertion order, then holiday columns `sort_by(|a, b| a.name.cmp(&b.name))` on
`{name}_delim_{±off}`. Regressors **append after** that sort; do not put them inside it.

**The `predict` value channel (NOT `feature_row`)** — `regressors.rs::predict_points` keeps
`feature_row` keyed on `day` and writes regressor cells *beside* the row:
```rust
let base_k = d.k - regs.len();
let base_cols = &d.cols[..base_k];
```
`prophet::predict` (`prophet.rs:813`) is the signature that gains a per-row value channel.

**Row-loop hoist pattern to copy** — `prophet.rs:177-186 holiday_day_sets` + `feature_row`'s
`hol_sets.get(hi).is_some_and(...)`: build membership sets ONCE outside the row loop, and use
**total lookup** (`.get()`, not `[]`) because every `Design` field is `pub` and a library must
not panic on a caller-built slice.

### `events.rs` — NeuralProphet event block (service, autograd transform)

**Analog:** `.claude/skills/spike-findings-aprender/sources/013-np-events-autograd/src/events.rs`.

**Column expansion reuses the Prophet shape verbatim** (this is what makes D-29's
one-argument-two-models claim literal):
```rust
pub fn event_columns(events: &[EventSpec]) -> Vec<(usize, i64)> {
    let mut cols = Vec::new();
    for (ei, e) in events.iter().enumerate() {
        for off in e.lower_window..=e.upper_window { cols.push((ei, off)); }
    }
    cols
}
pub fn event_day_sets(events: &[EventSpec]) -> Vec<std::collections::HashSet<i64>> {
    events.iter().map(|e| e.days.iter().copied().collect()).collect()
}
pub fn event_row(day: i64, cols: &[(usize, i64)], sets: &[HashSet<i64>], out: &mut Vec<f32>) {
    for &(ei, off) in cols {
        out.push(f32::from(u8::from(sets[ei].contains(&(day - off)))));  // d + off == day
    }
}
```
> Port note: use the **total-lookup** form `sets.get(ei).is_some_and(|s| ...)` in-crate, per
> `prophet.rs::feature_row`'s IN-02 comment. The prototype indexes directly.

**Block init pattern** — one `Linear(E, 1)` composed BESIDE `NpModel`, init `std = sqrt(1/dim)`
mirroring the seasonality block:
```rust
let mut lin = Linear::without_bias(dim, 1);
let std = (1.0 / dim as f64).sqrt();
lin.set_weight(Tensor::from_vec((0..dim).map(|_| (rng.normal() * std) as f32).collect(), &[1, dim]).requires_grad());
```
`forward` is one `.add()` on `NpModel::forward`; both parameter sets go to one `AdamW`.

**Training-loop patterns from `np.rs::train` (`:585-615`) that the block must not break:**
```rust
let samples: Vec<usize> = if l == 0 {
    (0..n_grid).filter(|&i| d.grid_observed[i]).collect()   // D-27 lives HERE: index regressors by caller row
} else {
    (l..n_grid).collect()                                    // D-26: every grid row, imputed included
};
debug_assert_eq!(n, n_training_samples(d, l),
    "np::train and np::n_training_samples must agree about how many rows a request buys");
```
Plus `clear_graph()` after every optimiser step (D-10, tape is thread-local and unbounded),
and `weighted_huber` — never core's detached `SmoothL1Loss`.

```rust
if h.name.len() > MAX_HOLIDAY_NAME_LEN {
```

**New-field pattern** (D-20: `Option<_>` + `#[serde(default)]`, `deny_unknown_fields` untouched):

`RegressorArg` copies `HolidayArg` exactly: `JsonSchema` derive (drives the tool schema AND the
`knobs` set-equality test), `deny_unknown_fields`, `#[serde(default)]` on every optional.

**Contract-mirror pattern for D-34's `fit_np_event_cost_per_column`** (`types.rs::cost_bounds_match_contract`):
```rust
for (name, key, value) in [
    ("MAX_LOGISTIC_CHANGEPOINT_LAMBDA", "fit_max_logistic_changepoint_lambda", MAX_LOGISTIC_CHANGEPOINT_LAMBDA),
    ("prophet::POISSON_NORMAL_BRANCH_LAMBDA", "poisson_normal_branch_lambda", crate::prophet::POISSON_NORMAL_BRANCH_LAMBDA),

    let from_contract = constant_f64("forecast-tool-boundary-v1", key);
```
Use `constant_f64` for a real-valued coefficient (a per-column µs slope is conceptually real —
rounding it to fit `constant_u64` would make the mirror assert something weaker than the constant).
Doc-comment pattern: the constant's rustdoc carries the derivation, the rejected candidate, and
the test that pins it — see `MAX_NP_TRAIN_COST`'s doc block (`types.rs:220-258`).

**`door_surface` reader pattern** (`types.rs:543 enumerated_knobs`, `:626 enumerated_axes`) — a new
`ForecastArgs`/`RegressorArg` field is red until its `knobs` row exists, because
`schema_knobs()` walks `schemars::schema_for!` for each owner struct. **A new owner struct must be
added to that array** (it already lists `ForecastArgs`, `HolidayArg`, `ChronosArgs`):
```rust
for (owner, schema) in [
    ("ForecastArgs", serde_json::to_value(schemars::schema_for!(ForecastArgs))),
    ("HolidayArg",   serde_json::to_value(schemars::schema_for!(super::HolidayArg))),
    ("ChronosArgs",  serde_json::to_value(schemars::schema_for!(crate::chronos::ChronosArgs))),
] { ... }
```
And note the **vacuity-guard pattern** in `every_cost_ceiling_constant_is_named_by_an_axis`:
```rust
assert!(ceilings.len() >= 10,
    "vacuity guard: only {} ceiling constants found — the filter has stopped matching \
     and this test would pass by checking nothing", ceilings.len());
```
D-34's constant is named `fit_np_event_cost_per_column` — it does **not** start with `fit_max_`,
so it is NOT auto-captured by the ceiling filter and needs no axis of its own; confirm that
against the filter rather than assuming either way.

### The invariance harness (test / release gate, batch)

**Analog:** `sources/012-no-arg-bitwise-invariance/src/sig.rs` for the signature;
`crates/aprender-forecast/src/sc1_wall.rs` for "a release-gate sweep that lives in `src/` as a
`--lib`-reachable module" (the crate has **zero** `tests/*.rs` targets — every parity suite is an
in-crate `mod parity`, which is exactly how this crate avoids the CI-darkness trap in CONTEXT.md's
Discretion list).

**Hash pattern (f64 by `to_bits()`, `-0.0` normalised):**
```rust
pub fn f64(&mut self, v: f64) {
    let v = if v == 0.0 { 0.0 } else { v };   // -0.0 == 0.0, every other bit pattern significant
    self.bytes(&v.to_bits().to_le_bytes());
}
```

**Field-set pattern — `fit_seconds`/`predict_seconds` EXCLUDED, `diagnostics` hashed whole**
(this is the mechanism behind D-36's "absent when unused"):
```rust
pub fn signature(r: &ForecastResponse) -> u64 {
    let mut h = Hasher::new();
    h.str(&r.model); h.str(&r.freq);
    h.bytes(&(r.n_history as u64).to_le_bytes());
    ...
    h.f64s(&r.yhat); h.f64s(&r.yhat_lower); h.f64s(&r.yhat_upper); h.f64s(&r.trend);
    for (k, v) in &r.components { h.str(k); json(&mut h, v); }
    json(&mut h, &r.diagnostics);
    h.finish()
}
```
`serde_json::Map` is a `BTreeMap`, so object iteration is key-sorted and the signature does not
depend on insertion order — relied on by `components` and `diagnostics`.

**Mutation-proof pattern (not optional):** perturb one output f64 by 1 ULP and assert the
signature changes. A green invariance table with no falsification probe beside it is
indistinguishable from a broken harness.

## Shared Patterns

### Refusal messages are verbatim contracts
**Source:** `forecast.rs:112-130`, `:192-315`; e2e cases string-match them (plan 06-06).
**Apply to:** every new refusal (D-26 gap rule, D-28 multiplicative-on-NP, D-21 generally).
Shape: `"<field> is <arm>-only; set model to \"<arm>\""` or `"<what was exceeded> <number>; <the fix>"`.
Each message names **the limitation and the fix**; never echo attacker-controlled strings back.

### A bound is contract-owned and test-mirrored
**Source:** `types.rs::bounds_match_contract` / `cost_bounds_match_contract` +
`test_support::constant_u64` / `constant_f64`.
**Apply to:** D-34's `fit_np_event_cost_per_column`, and any regressor-count/column bound.
Two copies of a number is the defect this pattern exists to prevent.

### `door_surface` is enforced, not asserted
**Source:** `types.rs` `enumerated_knobs` / `schema_knobs` / `every_cost_axis_names_a_real_bound` /
`every_cost_ceiling_constant_is_named_by_an_axis` — checked in BOTH directions, with a vacuity guard.
**Apply to:** every new `ForecastArgs` / `RegressorArg` field and every amended axis.

### Hoist the per-row set out of the row loop, and look it up totally
**Source:** `prophet.rs:177-186` + `feature_row`'s `hol_sets.get(hi).is_some_and(...)`.
**Apply to:** the event indicator expansion on the NP arm.

### Tests live in `src/` as `mod parity` / `mod tests`
**Source:** `prophet.rs:1273`, `np.rs:765`, `chronos.rs:544`, `bolt.rs:1220`; the crate ships **no**
`tests/*.rs` target at all.
**Apply to:** the regressor parity ladder, the event recovery bar, and the invariance harness —
this keeps them inside CI's `cargo nextest run --workspace --lib` with no `.github/workflows/ci.yml`
edit (which is a check-in-before-acting item).

### Re-mutate a guard in its new scope
**Source:** CLAUDE.md Verification Discipline rule 4.
**Apply to:** D-33 — `cost_bounds_match_contract` and the holiday position tests must be
re-mutated against the neuralprophet arm. The old proof does not transfer.
