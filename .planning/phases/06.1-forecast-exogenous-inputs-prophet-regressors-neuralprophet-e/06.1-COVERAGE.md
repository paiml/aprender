# API Coverage — Phase 06.1

No external API integration: this phase adds numeric and MCP-argument surface to ports that are already vendored in-tree (`crates/aprender-forecast`, `crates/aprender-mcp-forecast`), and the only external artifact anywhere near it — the Python Prophet 1.4.0 oracle — is consumed as committed fixture FILES under `crates/aprender-forecast/tests/fixtures/`, never called at build or run time.

## Why this declaration and not a matrix

The `api-coverage` detector was run over the phase scope at plan time and returned
`detected: false`. This declaration is written anyway, deliberately, because the seal-time
gate re-runs the detector over a scope that will then INCLUDE the eight PLAN.md bodies — and
those bodies necessarily use the words "MCP", "wire" and "endpoint" while describing an
argument surface on a server that already exists. A detector flip at seal time would block
the seal with nothing to read. Per the capability's own rule, a reasoned declaration is
accepted in place of a matrix when the phase genuinely integrates no external API, and the
reason is required exactly as an opt-out reason would be.
