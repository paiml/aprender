<objective>

reference's precision (D-03: fit in f64, store f32). Near the optimum the softmax-NLL gradient
norm approaches f32 epsilon (~1.2e-7); an f32 Wolfe line search can stall and report progress it
did not make. This is the first-wave contracted change RESEARCH Open Question 4 prescribes.

Purpose: Unblocks TRN-04 (deterministic L2 multinomial head with explicit convergence) — the head
supplies only the objective and gradient; convergence semantics come from this solver.
Output: private float-generic core, non-generic public f32 `LBFGS` (zero API break, proven by a
recorded golden trajectory rather than by "it still compiles"), `LbfgsF64` entry point, f64
contract-test twins, the four-channel non-finite matrix, version-bumped lbfgs-kernel-v1.yaml.
</objective>

**Review fix — the shape is NOT a generic default type parameter.** Codex: "Replacing the public
struct with a generic alias/default parameter can still be a Rust semver break." Turning
`pub struct LBFGS` into `pub struct LBFGS<T = f32>` breaks any downstream `use` in a turbofish or
trait-bound position and changes the type's kind. The required shape is therefore: a PRIVATE
generic core, a public NON-generic `LBFGS` (f32) whose signature is byte-identical to today's, and
a public NON-generic `LbfgsF64` beside it.
