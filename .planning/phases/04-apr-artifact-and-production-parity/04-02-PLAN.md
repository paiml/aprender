## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| view -> artifact bytes | everything a consumer will trust is fixed here; nondeterminism or smuggled env data undermines the hash chain |
| embedded sub-documents -> artifact | opaque JSON from another crate crosses into the artifact; a silent null is a lost non-finite value |
