adapter whose shape verify.rs's module docs literally prescribe — and prove APR-03: the trusted
policy closes the model, reloads the real `setfit-apr-v1` bytes, survives the byte-canonical
closure check at `Tolerance::EXACT`, and the SAME bytes load through the production core loader.

Purpose: the format swaps behind the seam; the check does not change (Ph3 D-07 as amended).

**Review findings closed here.** B3 had two halves. The first — provenance had no home in
`SetFitBundle`, so a serialized doc could not be fully recovered — is closed by plan 04-13 (bundle
field 20). The second is closed here: this plan carries an explicit, executable field-by-field
bijection proof rather than an assumption that closure will hold. The related HIGH finding on error
mapping is also closed: `CodecError::Bundle { source: BundleError }` cannot carry a
`SetFitArtifactError`, so a new `CodecError::Artifact` variant is added rather than stringifying
the typed source the seam's own docs insist on preserving.
