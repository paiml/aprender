<objective>
Close review finding B3's root cause: the artifact is contracted to carry data/model provenance
(APR-01) and inspection is contracted to recover a data fingerprint (APR-05), but `SetFitBundle` —
the value the codec must reconstruct from artifact bytes — carries no provenance at all. Its
`resolved_config` record holds exactly one field (`resolved_device`). Anything in the artifact that
is not a bundle field and not a deterministic function of bundle fields is unrecoverable, so
`serialize(deserialize(bytes)) == bytes` would fail the moment provenance is written.

This plan adds bundle field 20: a `ProvenanceRecord` assembled from the run's own selection and
dataset. It is the smallest change that makes byte-canonical closure achievable while satisfying
APR-01 and APR-05 honestly.

It also lands the completeness gate for 04-01 item 3's nullable-path allowlist. `aprender-train` is
the only crate that can name all five embedded sub-document types (`EncoderArchitecture`,
`SetFitTrainConfig`'s private wire, `ResolvedConfigRecord`, `EvidenceSummary`, and the
`ProvenanceRecord` this plan adds), so it is the only place the allowlist's completeness can be
asserted mechanically rather than trusted.

Purpose: make the contract's bijection table true in code before the codec (04-05) has to satisfy it.

Output: ProvenanceRecord, bundle field 20, schema-version bump, the allowlist completeness gate,
threading through the trusted assembly path and the two test modules that call it, tests.
