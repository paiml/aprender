**Layer 2 — the one door.** Add
`fn resolve_committed_evidence_path(cell: CellKey, bench_dir: &Path, kind: EvidenceKind, declared:
&str) -> Result<PathBuf, BenchGateError>`, and make it the ONLY way a row-supplied string reaches
the filesystem. Two stages, in this order, and the order is the property:

1. **Syntactic, total, filesystem-independent.** Refuse when `declared` is empty or whitespace-only;
   when `Path::new(declared).is_absolute()`; when any `std::path::Component` is `ParentDir`,
   `RootDir` or `Prefix`. `Component::CurDir` is ALLOWED (`./locks/x.json` names the same file).
   This stage runs before any `fs` call, so it gives the same verdict whether or not the file
   exists — which is what stops a "does not exist" answer from masking an escape.
2. **Canonical containment.** Join onto `bench_dir`, then canonicalize BOTH the joined path and
   `bench_dir` (`fs::canonicalize`), and require
   `canonical_target.starts_with(&canonical_bench_dir)`. Use `Path::starts_with`, which is
   COMPONENT-wise — `str::starts_with` would accept `<tmp>/bench-evil/x.json` under a bench_dir of
   `<tmp>/bench`, and Task 3's case table has a row that goes red on exactly that mistake.
   Canonicalizing `bench_dir` too is not optional: on macOS `/tmp` is itself a symlink to
   `/private/tmp`, so comparing a canonical target against a non-canonical base rejects every
   legitimate path under a temp dir. This stage is what catches a SYMLINK, which stage 1 cannot
   see. When canonicalizing the TARGET fails with `ErrorKind::NotFound`, return
   `EvidenceFileMissing` for `kind` — an absent file is not an escape and must not be reported as
   one; any other canonicalize error becomes `EvidenceReadFailed`.
