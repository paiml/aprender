<objective>
Close D-18: make a collapsed epsilon window a HARD FAILURE of the calibration derivation, instead
of a line of prose printed beside `rc=0`.

Verified, not inferred: 05-01's four-cell combine exited `rc=0` while printing `EMPTY` five times.
Separation is *asserted* (`ctrl_max < real_min`); `supports_margin` is only *reported*. A run that
reports success with an empty epsilon basis is theatre in exactly the surface F-10 exists to
protect, and a green run is therefore not evidence that an epsilon basis exists.

The fix is structural, not a new assertion bolted on: the window rule currently exists as inline
arithmetic in TWO places (the fixture matrix's basis table and the production matrix's), which is
why 05-01 had to fix the `eps/noise` trap twice to keep it from surviving in a sibling report.

from the regime's own frozen table rather than from a local knob, and carries coverage as a typed
value so a provisional basis cannot be mistaken for a freezable one.
