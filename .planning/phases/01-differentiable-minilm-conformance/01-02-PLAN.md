  plan 01-06's encoder tests reuse it instead of duplicating it.

```rust
// Extension to nn/module.rs — default methods with POSITIONAL FALLBACK, leaf/composite overrides (D-17)
pub trait Module: Send + Sync {
    // ... existing: forward, parameters, parameters_mut, train, eval, training ... UNCHANGED

    /// Named parameters. Leaf names are local ("weight", "bias");
    /// composites prefix with a dotted path.
    ///
    /// INVARIANT (holds for every implementor, including non-overriding ones):
    /// `named_parameters()` has the same length as `parameters()`, and element `i` of each
    /// refers to the same tensor. The DEFAULT satisfies this by emitting stable numeric
    /// names ("0", "1", ...) over `parameters()`. Overriding to supply semantic names is
    /// therefore always safe and never changes arity or order.
    fn named_parameters(&self) -> Vec<(String, &Tensor)> {
        self.parameters()
            .into_iter()
            .enumerate()
            .map(|(i, t)| (i.to_string(), t))
            .collect()
    }
    fn named_parameters_mut(&mut self) -> Vec<(String, &mut Tensor)> {
        self.parameters_mut()
            .into_iter()
            .enumerate()
            .map(|(i, t)| (i.to_string(), t))
            .collect()
    }

    /// Recursive mode propagation (existing train()/eval() are flat, leaf-local).
    fn set_training(&mut self, training: bool) {
        if training { self.train() } else { self.eval() }
    }
}
```
HF-dotted full names (e.g. `encoder.layer.0.attention.self.query.weight`, D-18) are composed by
the encoder composite in plan 01-06 — this plan guarantees leaf names, prefix mechanics, and the
universal arity/order invariant.
