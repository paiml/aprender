<objective>
Repair the two confirmed numerical/graph defects that would make Phase 1's own conformance gates
produce wrong verdicts, both surfaced by cross-AI review and both verified against live source by
the orchestrator and again during this planning pass:

1. **Detached, incorrect broadcast attention mask** (`nn/transformer/positional_encoding.rs:366`).
   `add_mask` returns `scores.add(mask)` — which records a graph edge — ONLY when the two shapes
   match exactly. Otherwise it falls through to
   `Tensor::from_vec(scores.data().iter().zip(mask.data().iter()).map(|(&s,&m)| s+m).collect(), scores.shape())`.
   That fallback has two independent defects: (a) no `requires_grad_` / `set_grad_fn` / `with_graph`
   block, so it is exactly the PMAT-913/914/922 severed-graph class this phase exists to eliminate;
   and (b) `.zip()` truncates to the shorter iterator, so a `[B,1,1,S]` mask against `[B,H,T,S]`
   scores writes the mask over only the first `B*S` elements and leaves the rest unmasked — it never
   broadcasts correctly at all. Amendment **A-02** puts this in Phase 1 scope.

2. **`Tensor::gelu` is the tanh approximation** (`autograd/ops/activation.rs:110-140`, doc comment
   verbatim: "Uses the tanh approximation"). The pinned MiniLM config sets `hidden_act: "gelu"`,
   which in HF means the exact erf GELU. Layer-by-layer FFN parity fixtures would fail against a
   correct implementation, and widening the FFN tolerance to absorb the difference is explicitly
   forbidden. Amendment **A-03** adds an exact erf GELU as a seventh primitive.

Purpose: both defects sit upstream of every ENC-03 parity gate. Fixing them in wave 2 means the
01-03 spike (wave 3) and the 01-06 encoder (wave 4) are built on correct primitives instead of
discovering the defects mid-wave.
Output: repaired `add_mask` with broadcast + graph tests; `Tensor::gelu_exact` with FD test,
independent high-precision erf oracle, and a differential test against the tanh variant.
</objective>

`GeluExactBackward { x: Tensor }` in `grad_fn.rs`, registered in `test_all_backward_names`.
Derivative: `d/dx [x * Phi(x)] = Phi(x) + x * phi(x)` where
`Phi(x) = 0.5 * (1 + erf(x / sqrt(2)))` and `phi(x) = exp(-x^2 / 2) / sqrt(2*pi)`.

Available erf in-tree (already a non-optional dependency of aprender-core — no new package):
`batuta_common::math::erf(f64) -> f64` and `erf_f32(f32) -> f32`
(`crates/aprender-common/src/math.rs:22,43`). NOTE its documented accuracy: Abramowitz & Stegun
7.1.26, max absolute error 1.5e-7. Task 2 measures whether that is sufficient and states the
fallback if it is not.
