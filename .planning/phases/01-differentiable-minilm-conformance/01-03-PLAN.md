- **`l2_normalize_rows` returns `Result<Tensor, OpError>`.** The previous signature declared a bare
  `Tensor` while the same plan promised typed rank validation — those cannot both be true.
- **The epsilon clamp derivative is piecewise and is now specified as such.** For
  `y = x / max(||x||, eps)`: ABOVE the clamp the derivative is the projected unit-normalization
  Jacobian `(I - y y^T) / ||x||`; BELOW it the denominator is the CONSTANT `eps`, so the derivative
  is simply `I / eps`. Silently applying the projected form below the clamp is wrong. Cosine
  similarity has the identical clamp structure and the identical requirement. FD tests must cover
  BOTH branches.
- **The gradient assertion is restated.** "Every parameter tensor has a non-zero gradient" is
  mathematically unsatisfiable against a correct BERT implementation (`attention.self.key.bias` is
  exactly zero — see the ENC-04 gate wording in the contract authored by 01-01). The spike now
  asserts finite-everywhere plus non-zero AGGREGATE per component.
- **"Gradients differ across batch rows" is replaced with a well-defined test.** A single combined
  backward does not expose per-row contributions; the spike now runs SEPARATE per-row scalar losses
  and compares the resulting gradients, which is measurable.
- **Wave 2 -> wave 3, and now depends on 01-09.** The attention-mask broadcast defect is a known
  fact, not a possible discovery: 01-09 repairs it in wave 2, and this spike becomes its end-to-end

`OpError` is the shared enum created in plan 01-01 (extend with variants as needed — e.g.
`InvalidEpsilon { eps }`, `InvalidRank { expected, got }`; do not rename existing variants).
Rowwise backward loops copy the SoftmaxLastDimBackward rows-by-features iteration.

**Piecewise derivative of the clamp (both ops):**
```
n = ||x_row||_2 ;  d = max(n, eps)
if n >  eps :  dy/dx = (I - y y^T) / n        # d depends on x — projected form
if n <= eps :  dy/dx = I / eps                # d is a CONSTANT — no projection term
```
The branch boundary is exactly `n == eps`; pick one side deterministically (use `n > eps` for the
projected form) and document it. The same structure applies to the cosine denominator
`max(||a||, eps) * max(||b||, eps)`: each factor is independently clamped, giving four branch
combinations, and the derivative drops the corresponding `a`/`b` projection term whenever that
factor is clamped.
