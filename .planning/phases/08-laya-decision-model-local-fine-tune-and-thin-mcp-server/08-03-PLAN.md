- `gemm.rs`: `Linear { w, b, out, inp }` (weight `[out, in]` row-major is the GEMM A operand, no
  weight transpose — spike-020 layout) and `transpose`; `Linear::forward(&self, x, m)` returns
  `Result<Vec<f32>, ModernBertError>` instead of panicking on a `gemm_blis` error (typed error, no

- `layer.rs`: `layer_norm(x, d, w, b: Option<&[f32]>, eps: f64)` with f64 mean/var accumulation and
  the config's `norm_eps` passed in by every caller (review finding: the spike hardcoded 1e-5, so a
  parsed-but-ignored `norm_eps` would let a supported-looking config drift silently; Laya's config
  says 1e-5, so honouring it keeps parity);

  tests below — RESEARCH A11); `rope_rotate_half(x, l, heads, hd, theta)` with the torch f32
