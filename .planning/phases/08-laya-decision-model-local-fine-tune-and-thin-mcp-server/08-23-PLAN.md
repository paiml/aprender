<objective>
Close the request half of class B and the served half of class A on the stdio server crate, and its
share of V14-c and IN-05: count before materialising texts, enumerate every request-derived size and
every served field in the tool-boundary contract, and sweep both tables with tests that fail when a
row loses its bound or its source.

Purpose: the contract says the count is "checked FIRST, before any text is read", but pmcp builds a
JSON tree and parse_args builds a Vec<String> before precheck counts (V5-c: 3M empty texts -> 764 MB
RSS on stdio). The served fields are D-11's identity promise; after plan 08-19 each has a bound
source, and this plan writes down which, so a new served field cannot ship unbound.

Output: count-first parsing (tested over live stdio), clap in main.rs, the narrowed allow, two
contract tables with sweep tests, and a mutation record.
</objective>
