## Sampling Rate

- **After every task commit:** Run the quick run command
- **After every plan wave:** Run the full suite + `make contract-validate` (new contracts added to `CONTRACTS`) + `bash scripts/check_contract_test_binding.sh` (CI's strict-binding gate — a contract may never cite a test that does not exist yet)
- **Before `/gsd-verify-work`:** Full suite green, gated full-model parity run pasted, `just laya-pack` / `just laya-verify` passing (gate recomputed in Rust), live deploy checkpoint resolved and the `accepted_region_cold` binding matching its outcome
- **Max feedback latency:** 120 seconds (quick run)
