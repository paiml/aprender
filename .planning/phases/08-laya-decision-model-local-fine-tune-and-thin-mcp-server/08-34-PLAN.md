   approval, and when it is `unreachable` GREEN cannot happen and the run is worth its ~90 minutes only as
   the BLOCKED-ATTRIBUTED record of the real Linux reds — the owner decides.
3. Ordering and heads. The records are bound to heads by ancestry (see Task 2): the regression runs on code
   head H; the pushed tip P is H plus docs-only commits; the evidence commits after P stay LOCAL, because a
   docs-only push would restart CI and void the approval.

in a GREEN, BLOCKED-ATTRIBUTED or BLOCKED-PHASE8 record.
