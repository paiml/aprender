<objective>
Build the decide-apr-v1 artifact (D-17): the packer library that turns a Laya run dir into one .apr,
the bounded load ladder that is the ONLY way to a verified `Decider`, contract-resident probes, and the
model identity the classify response will carry (D-11) — proven on the tiny fixture in CI.

Purpose: D-17 makes .apr the served format, carrying task, recipe, calibrated temperatures, gate
report and input hashes, with the base declared (D-04). The ladder is what makes "the served model is
the evaluated model" a property every process re-proves. The recommended conversion path is a Rust
packer on apr-format's `AprV2Writer` (one container implementation; a Python writer would be a second
one and could not run the Rust re-score — RESEARCH Alternatives).

Output: `src/artifact.rs`, `src/pack.rs`, `Decider` + `ModelIdentity` in `src/lib.rs`, trybuild UI
test, the golden sha256.

Recorded choices: (1) `safetensors` becomes a normal dependency of `aprender-decide` because the pack
module is library code; the SERVED path reads only .apr — servers never call `pack` — which the
CLAUDE.md row in plan 08-12 states so the SafeTensors carve-out is not widened. (2) The manifest is
stored as the STRING value of the single custom key, serialized from typed structs, so its bytes are
identical whichever serde_json map backing the build has (the D-ITEM-05-17-A class of defect).
(3) Gate POLICY (refuse a failing report, thresholds must equal the contract) is NOT in this plan's
`pack_run_dir`: it lives in plan 08-09's pack CLI and `check_gate_report`, so the tiny fixture's
honest `pass: false` report can still be packed for tests.
</objective>
