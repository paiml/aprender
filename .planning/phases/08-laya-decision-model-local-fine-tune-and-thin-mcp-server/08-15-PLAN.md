## Rules this plan implements (from the contracts, not re-decided here)

- bound(c, s) = max(floor, k x noise(c, s)); floor = `equations.pack_rescore_probs_abs.float_tolerance`,
  k = `constants.pack_rescore_noise_k`, ceiling = `constants.pack_rescore_bound_max_abs` (laya-parity-v1).
- noise(c, s) = max over rows and components of |f64(p_torch32) - p_f64|, recomputed from the stored
  numbers; the reported value must equal it exactly (both are the max of exact f64 differences).
- Absent `rescore_noise_sha256` -> both sets at the floor. Ceiling exceeded -> refused.
- Median: rank_key = floor(ece_post x rank_scale) as i64; order by (rank_key, seed); index (N-1)/2.
- Legacy (no `seed_selection`): refused `SeedPolicyMissing` only after the gate passes.
- Shift probe: recomputed, never re-scored, never a gate clause.
- Every new refusal is exit code 2 (`VerifyError::exit_code`); `GateFailed` stays 3.
