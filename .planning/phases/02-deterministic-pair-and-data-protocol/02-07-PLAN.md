## Review corrections incorporated (02-REVIEWS.md)

Codex rated this the phase's riskiest plan (seven HIGH findings) and Gemini its only MEDIUM. Every
one is addressed below.

- **F1 / Codex blocking #4 — the negative sampler was O(K²), violating DATA-05.** Prefix sums over
  every unordered class pair cost O(K²) state, which breaks the bound exactly when K approaches N
  (many singleton classes, small budget). **Replaced by an O(K) scheme** whose marginal is
  provably identical: keep per-class weights `w_c = n_c · (S − n_c)` with `S = Σ n_i` (an O(K)
  array summing to `2 · negative_capacity`), draw the first class against those weights, draw the
  first endpoint uniformly inside it, then draw `t` uniformly in `[0, S − n_j)` and map it to a
  global bucket index skipping class j's contiguous block. Sampling ordered cross-class endpoint
  pairs uniformly induces exactly the `n_j · n_k` weight on each unordered class pair, so D-14's
  semantics are unchanged. Task 2 must include the equivalence argument in comments and a
  statistical test.
- **F2 / Codex 02-07 HIGH — zero-positive, zero-negative, single-class, all-singleton,
  zero-budget, zero-hard-cap, and odd-budget were undefined and strict alternation fails for
  several.** A typed, version-tagged degenerate policy is defined for every case (Task 1) and each
  has a named test.
- **F3 / Codex 02-07 HIGH — "explicit budget wins" bypassed the hard cap, defeating its DoS
  role.** Resolved by the stronger of the two options Codex offered: the cap binds explicit
  budgets, and an over-cap request is `BudgetExceedsHardCap` — a loud failure, not a silent
  truncation of a number the user typed. Raising the cap is an explicit, auditable act.
- **F11 / Codex 02-07 HIGH — capacity functions returned `u64` but needed checked arithmetic, and
  `pair_at` was infallible despite real failure modes.** All capacity functions return
  `Result<u64, ContrastiveDataError>`; `pair_at` returns `Result<LabeledPair, _>` with
  `OrdinalOutOfRange`.
- **F12 / Codex 02-07 HIGH — hashing only pair bytes did not commit the replay tuple.** The hash
  is now `SHA-256(replay_record_canonical_bytes ‖ 0x1E ‖ streamed pair bytes)`.
- **F13 / Codex 02-07 MEDIUM + 02-08 HIGH — an untrusted pair's supplied target was not validated,
  and a trusted pair type with a private constructor cannot represent poisoned input at all.**
  `UntrustedPairRecord` + `parse_pair_dump` + `validate_pair_records` are added; this is also what
  makes plan 02-08's endpoint-poisoning test constructible.
- **F14 / Codex 02-08 HIGH — `#[cfg(test)] fn retained_state_size` is invisible to external
  integration tests.** Replaced with a stable, unconditionally public diagnostics object
  (`SamplerStateReport` + the `RetainedState` trait), which is the third of the three options the
  orchestrator sanctioned. A `test-support` feature plus a self dev-dependency was considered and
  rejected: feature unification across the lib and test targets is a known duplicate-crate hazard,
  and a plan should not gamble a headline gate on a cargo trick.
- **Codex 02-07 LOW — shipping a unique-capacity error without a unique strategy creates dead
  API.** Accepted with a scope note rather than removed (D-11 is locked): the capacity check ships
  as a public, documented, tested helper explicitly labelled as pre-provisioned for a strategy not
  present in v1.
- **F18 / Codex cross-plan MEDIUM — frontmatter omitted shared test modules.**
  `tests/common/mod.rs` is now listed, since this plan extends it with pair fixtures.
