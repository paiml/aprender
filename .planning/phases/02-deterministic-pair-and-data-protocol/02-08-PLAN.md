## Review corrections incorporated (02-REVIEWS.md)

Both reviewers praised this plan's negative-testing philosophy; every correction below is about
whether the tests can actually be written against the API.

- **F14 / Codex 02-08 HIGH — `negative_materializing.rs` could not call the proposed
  `#[cfg(test)] fn retained_state_size`.** A library method under `#[cfg(test)]` is invisible to
  external integration tests, which are separate crates. Plan 02-07 now exposes a stable public
  `SamplerStateReport` + `RetainedState` trait; this plan's gate calls that, and the in-band
  MaterializingSampler implements the SAME trait so the gate is literally one call for both.
- **F13 / Codex 02-08 HIGH — "replace a pair endpoint with a validation ID" conflicts with the
  structural `SelectedId` private-constructor design.** A trusted `LabeledPair` cannot represent
  poisoned input by construction. The poisoning test now builds `UntrustedPairRecord`s (plan
  02-07) and runs them through `validate_pair_records`, which is the real untrusted boundary.
- **V1 / Codex 02-08 HIGH — the compatibility trybuild case could not prove a runtime profile
  property.** Plan 02-03 made profile a type parameter, so the two compatibility cases are now
  genuinely non-compiling: `PreparedDataset<Compatibility>` cannot be passed where
  `&PreparedDataset<Canonical>` is expected, and it has no `validation_witness` method at all.
- **F1 / Codex 02-08 HIGH — testing only three classes could never expose the O(K²) class-pair
  state.** An adversarial K = N all-singleton layout under a fixed small budget is now a required
  case, cross-checked against plan 02-04's `[1]*32` contracted fixture.
- **F18 / Codex 02-08 MEDIUM — mutation fixes can modify any source file but the frontmatter
  listed only two negative tests.** `files_modified` now includes `crates/aprender-contrastive-data/src/`,
  the shared test module, the binding registry, and the Makefile.
- **F18 second half / Codex 02-08 MEDIUM — a 300-second timeout per mutant can run for hours.**
  The run is bounded: `--timeout 60` per mutant (this crate's full test suite runs in seconds) and
  an overall `timeout 2700` wrapper whose expiry is reported as a partial result rather than
  silently accepted.
- **F9 / Codex 02-02 HIGH (cross-plan) — `pv validate` checks contract SHAPE, not binding
  coverage, and no plan updated `contracts/aprender/binding.yaml`.** This plan is the phase's
  single owner of that file (two plans appending to one YAML list would collide) and adds the
  `contract-audit-phase2` target as a BLOCKING tier3 gate.
- **F20 / Codex 02-02 MEDIUM + Gemini §4.2 — the crates.io cascade.** The gate sweep runs
  `cargo package --no-verify` for both crates and records the required publish order; the
  verifying `cargo package -p apr-cli` is deliberately not gated, for the reason stated in plan
  02-02.
