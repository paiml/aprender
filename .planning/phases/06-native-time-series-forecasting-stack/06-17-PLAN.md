## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| forecast response -> client | `yhat_lower` / `yhat_upper` are consumed as an interval with a stated width; a sampler with the right mean and the wrong spread produces bands that are quietly narrower than advertised |
| `POISSON_NORMAL_BRANCH_LAMBDA` -> the sampler's algorithm | a single constant decides whether a request gets an exact draw or an approximation, in a regime the contract itself says the approximation is not standard for |
| `Design`'s public fields -> `predict` | every field is `pub`, so a caller can construct a `Design` whose `spec.holidays` and `cols` disagree and reach `feature_row` with a mismatched slice |
| test suite -> the claim "this is correct" | a bar on one statistic that a degenerate implementation satisfies is a green suite that means nothing |

Scope note: a stateless local numeric door with no authentication, no persistence and no PII. This
plan's threats are to OUTPUT INTEGRITY and to the integrity of the evidence, not to availability.
