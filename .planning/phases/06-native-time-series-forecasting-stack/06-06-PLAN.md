`pool_equality` unit test previously hard-asserted `speedup >= 2.0` under

`pool_equality_under_load` (unit-test-falsifiable) and `pool_speedup_host_gated` (benchmark-falsifiable).

needs the real `"neuralprophet"` arm, which moved from 06-01 Task 3 to 06-04 Task 1. This plan moves to
Wave 4 because 06-05 — still a dependency for `crate::chronos` — moved to Wave 3 behind 06-04.

**REVIEW-06-U2 — INCORPORATED.** Task 2 adds four malformed-date e2e cases (trailing content, empty string,
surrounding whitespace, non-ASCII) against the strict `parse_date` 06-01 now writes.

**REVIEW-06-U1 — INCORPORATED (wording).** The threat register no longer describes `FIT_BUDGET_SECS` as a
