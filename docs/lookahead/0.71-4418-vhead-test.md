## The V-head test cannot fail on one mutant

`reorder_v_heads_is_key_major_to_value_major` only uses nk=2, nv=4, so
nv/nk = nk = 2. At those sizes the permutation is its own inverse, and a
mutant that swaps the roles of `nk` and `nv / nk` passes all four of its asserts.
A direct port of `reorder_v_heads` (qwen35_gguf.rs:149-168) gives:

| case | correct | swap mutant |
|------|---------|-------------|
| four existing asserts | pass | pass (mutant not killed) |
| nk=3, nv=6, hd=1 | `[0,2,4,1,3,5]` | `[0,3,1,4,2,5]` |
| nk=3, nv=6, hd=2 | `[0,1,4,5,8,9,2,3,6,7,10,11]` | `[0,1,6,7,2,3,8,9,4,5,10,11]` |

to `1af0e3cc11` (`git apply --check`). It has not been compiled or run: the
