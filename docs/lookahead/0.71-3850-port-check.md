## On main

refuses a recorded GGML type that has no GPU kernel, instead of decoding it as
Q4_K. It reached main in the v0.69.3 merge-back (`5fa13fe8c6`, #4338). A
name absent from the map still resolves to Q4_K, on purpose.

because PR #4372 was closed without merging. Neither commit is an ancestor of
