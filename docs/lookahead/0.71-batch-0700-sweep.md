Measured 2026-10-05, git only. PR #4372 (`batch/0.70.0`) was closed without
merging, so the issue comments that say "landed in batch/0.70.0" are claims
to check against `origin/main`.

**Method.** `git cherry origin/main batch/0.70.0` lists 322 commits whose
patch is not on main. Ten 0.71 issues were checked against them. Patch-id
misses a squashed port, so each hit was then checked by file content
on main.

The other six (#3574 #3602 #3759 #4444 #4485 #4486) have no fix commit on
`batch/0.70.0` that main lacks; full commit messages were searched, not only
subjects. One evidence-only commit cites #3602: `45dbba23c5`, the PMAT-3739

The other two are true, but nothing records it: #4096's fix and #3714's code
are on main under commits that do not name them.
