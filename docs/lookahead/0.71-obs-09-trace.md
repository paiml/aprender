**What V6 asks.** `apr serve` runs the existing `inference_trace` tracer for a request that sends
`X-Trace-Level: step|layer` and returns the timings in an `apr-trace-v1` receipt. Tracing is off by default.
The same receipt is the before/after unit of OBS-11: every 0.71 performance PR carries a trace diff, so

**Design points.**
- **Double-counting.** The step vocabulary is the `TraceStep` enum. Attention, FFN, layer norm, kernel launches and brick profiles run inside `transformer_block`, so only the top-level steps are summed against the wall.
- **Honest provenance.** `Measured` requires `tracer.ran` and at least one event. A receipt that is not measured is RED rather than "estimated": the ledger holds no unmeasured timings.
- **Comparable diffs.** A diff pair must share host, model, backend, prompt and level, and must run different binaries. Anything else is REFUSED, never reported as a speed-up.
