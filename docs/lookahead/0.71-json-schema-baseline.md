## What this means for 0.71

- **001 and 002 are parity targets.** The reference meets them 10/10 on a 0.5B model.
- **003 is beyond the reference.** llama.cpp silently drops the unknown keyword, which is
  the exact behaviour the contract forbids. An apr result of HTTP 400 on 003 is a beat, not
  parity. A baseline cannot be "match llama.cpp" for this falsifier, and a review should
  not hold apr to the reference here.
- **The like-for-like form is the server path**, not `llama-cli --json-schema`: all three
  falsifiers go through `/v1/chat/completions`.
