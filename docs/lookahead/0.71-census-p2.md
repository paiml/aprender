# 0.71 census P-2: count what the walk skips by name (#4709)

`0.71-census-p2.patch` applies on top of `0.71-census-p3.patch` (branch
`la-71/census-p3`), both against main at this branch's merge-base:

    git apply docs/lookahead/0.71-census-p3.patch
    git apply docs/lookahead/0.71-census-p2.patch

It is option (b) of the proposal in `0.71-census-proposals.md`: keep the
skip and report it. Option (a), walking `kaizen/`, stays open; this patch
makes the size of that decision visible on every census run.

## Change

- `crates/aprender-contracts/src/lint/gates.rs`: the five names the walker
  skips become one exported `SKIPPED_DIRS` list. The two old comments move
  onto it. The walk is unchanged.
- `crates/aprender-contracts-cli/src/commands/census.rs`: a new
  `skipped_by_name` map, from each skipped name to the number of `.yaml`
  files under directories of that name. The top-level `quarantine/` stays
  `quarantined_n`'s and is not counted twice. A nested `quarantine/` is
  counted here, because `quarantined_n` never sees it. The table prints
  one line, `skipped by name: kaizen/ 46, publish-manifests/ 3`, when the
  map is not empty.
- `n_files`, `n_parsed`, `by_anchoring` and the release step do not
  change.

## Measured on the tree (find; not yet the patched binary)

| Name | Files | Directories |
|---|---|---|
| kaizen | 46 | `contracts/entrenar/kaizen`, `contracts/trueno/kaizen` |
| publish-manifests | 3 | `contracts/publish-manifests` |
| legacy, pipelines, quarantine | 0 | none |

So the expected map on main is `{"kaizen": 46, "publish-manifests": 3}`.

## Tests in the patch

- `files_skipped_by_directory_name_are_counted_by_that_name`: two
  `kaizen/` directories at depth 2, a `publish-manifests/` and a nested
  `x/quarantine/` give `{kaizen: 2, publish-manifests: 1, quarantine: 1}`,
  `n_files` 1 and `quarantined_n` 0.
- `quarantined_contracts_are_counted_and_not_censused` also asserts the
  map is empty, so the top-level `quarantine/` is not counted twice.
- The JSON key test lists `skipped_by_name`.

To run them, on the test host:

    cargo test -p aprender-contracts-cli --lib census

The RED proof: make `walk_skipped` return at once. The new test must fail
on the map. `scripts/check_census_derived.sh` does not pin the top-level
key set, so the new key does not need a change there.
