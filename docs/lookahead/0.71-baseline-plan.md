## Admissibility (all rows)

A baseline is admissible only if it records all of the following:
1. Model identity: file name, byte size and sha256. A label like "4B" is not enough.
2. The competitor pin as a full revision. llama.cpp must be `d1d3c3396`, resolved through `scripts/llama_pin.toml` / `scripts/llama_bin.sh`.
3. The apr binary as version+SHA, from `. scripts/apr_bin.sh`.
4. Zero failed requests. The `apr test llm bench` validator already refuses a run with any failed request, so a JSON written beside such a refusal is not a measurement.
5. Raw samples with a sha256, so that a median can be re-derived (FALSIFY-OBS-PERF on #4551).
6. A trace line or behaviour delta proving the backend that ran (CLAUDE.md verification rule 2).
