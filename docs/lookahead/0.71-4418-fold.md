## Why the extra test

The fix's four `reorder_v_heads` asserts use nk=2 or nk=nv, where the
regrouping permutation is its own inverse. So a mutant that swaps the
source and destination index (key-major vs value-major) passes all four.
At nk=3, nv=6 the permutation is [0,2,4,1,3,5] and the swap gives
[0,3,1,4,2,5], so the new test kills it. Checked by hand for hd=1 and
hd=2.
