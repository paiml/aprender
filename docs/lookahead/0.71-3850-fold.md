# 0.71 #3850 fold: the GPU path refuses unknown quant types

`0.71-3850-fold.patch` applies to main at 11f844a772. It is the fix
40d4367f4e (`fix(cuda): the graph path and LM head decoded unknown quant
types as Q4_K`, branch `PMAT-3850-resolve-qtype-refuses`, 1 ahead and 44
behind main), cherry-picked with `-n`, 0 conflicts, 4 files, +119/-27.

What it changes (from the fix's message): `graph_builder::ggml_code`
delegates to a new exhaustive `WeightQuantType::ggml_type`, instead of a
7-arm list ending `_ => 12`; `graph_dispatch::qtype_from_ggml` refuses a
code with no kernel, instead of `_ => Q4K`; the LM head refuses bytes that
match no layout, instead of `unwrap_or(Q4K)`.
