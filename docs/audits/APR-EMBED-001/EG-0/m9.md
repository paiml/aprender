## Findings the spec did not predict

1. **Both repos ship `mmproj` (vision and audio projector) files.** The spec's
   M3 / D-4 premise is text-only weights. The text GGUFs above carry no vision
   tensors; the projectors are separate files. I-7 (media refused) still holds.
2. **`context_length` metadata is 262144**; the model card says 8192. The
   truncation contract must take the card's limit, or the oracle's, not the key.
3. **`tokenizer.ggml.model = gemma4`**, not the SentencePiece model EG-1's text names. The
   vocabulary is still 262,144.
4. **`head_count_kv` per-layer values are invisible**: `apr inspect` prints the
   array as `[len=24]`. EG-1 needs the values; the shapes above give them meanwhile.
5. `apr flow` labels the file "decoder-only (LLaMA/Qwen2)" and `apr tokenize`
   falls back to greedy with `roundtrip: false`. Both exit 0, so both are silent
   wrong answers (probe receipt `a-probe-udq4.tsv`).
