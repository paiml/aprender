# apr export

Export model to other formats

**Category**: Model Transform

## Synopsis

```text
apr export [OPTIONS]
```

## Example

```bash
apr export model.apr --format gguf -o model.gguf
```

## Full help

Run `apr export --help` for the complete option list.
