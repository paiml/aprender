# apr explain

Explain errors, architecture, tensors, and kernel dispatch

**Category**: Inspection

## Synopsis

```text
apr explain [OPTIONS]
```

## Example

```bash
apr explain qwen2.5-coder-1.5b-instruct-q4_k_m.gguf
```

## Full help

Run `apr explain --help` for the complete option list.
