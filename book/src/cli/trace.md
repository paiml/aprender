# apr trace

Layer-by-layer trace analysis

**Category**: Inspection

## Synopsis

```text

```

## Example

```bash
apr trace qwen2.5-coder-1.5b-instruct-q4_k_m.gguf --prompt "What is 2+2?" --max-tokens 4
```
