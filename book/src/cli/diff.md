# apr diff

Compare two models

**Category**: Inspection

## Synopsis

```text
apr diff [OPTIONS]
```

## Example

```bash
apr diff qwen2.5-coder-1.5b-instruct-q4_k_m.gguf qwen2.5-coder-1.5b-instruct-q4k.apr
```
