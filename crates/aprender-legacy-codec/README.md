# aprender-legacy-codec

A serde codec that reads and writes the bincode 1.x legacy layout (fixint, little-endian) byte-for-byte, without the unmaintained `bincode` crate (RUSTSEC-2025-0141). It has no workspace-sibling dependencies.

Part of the [Aprender](https://github.com/paiml/aprender) monorepo.
