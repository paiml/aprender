# aprender-bench-tokenizer

Head-to-head BPE tokenizer benchmarks: aprender vs HuggingFace tokenizers v0.22

Part of the [Aprender](https://github.com/paiml/aprender) monorepo — 70 workspace crates.

## Install

```bash
cargo install aprender    # CLI binary
```

```toml
[dependencies]
aprender-bench-tokenizer = "0.29"
```
