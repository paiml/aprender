# FORMAT (one entry per line, TAB-separated):
#
#     <file>	<hash16>	<count>
#
# <hash16> is the first 16 hex digits of the sha256 of the matched LINE after
# tabs are turned into spaces, runs of spaces collapsed, and the ends trimmed.
# <count> is how many lines of <file> carry that key. Regenerate the list with
#

#
# and read an entry back with `--explain <hash16>`. The guard that enforces

# property. A line NUMBER is not part of a claim; the claim text is.
#

# lines anywhere in the file, reindenting, and re-aligning a markdown table
