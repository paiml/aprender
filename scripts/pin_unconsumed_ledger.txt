# THE SYMMETRIC GAP: apr's side of the protocol has no producer.
# ---------------------------------------------------------------------------
# The comparator's invocation is built by llama_comparator_server_flags from the
# declaration, and check_comparator_flags.sh refuses any drift. apr's side has
# no equivalent: scripts/parity_host_receipt.sh hand-writes `"$APR" serve run`
# and `"$APR" test llm bench` argument by argument. So the three keys that
# describe apr's invocation are declarations with no reader -- exactly the shape
# that let `-b 1` be retyped three times on the comparator side (#2737).
# Closing it means an apr-side producer, symmetric to the comparator's.
#
# harness_command left this list during the same change: joining http_stream to
# it made check_bench_protocol.sh read it. Its ARGUMENTS are still hand-written,
# so the join is partial -- but the key itself is now compared, and the ledger
# records only keys nothing reads.
