# cargo-mutants tests with default features, so a module behind `#[cfg(feature = "x")]` never compiles and every
# mutant in it reads MISSED, whatever its tests say. `--features pkg/feat` cannot be passed workspace-wide (cargo
# refuses it for a selected package that does not own the feature), so mutants_table_shard.sh runs each row below as
# its own `cargo mutants -p PACKAGE --features FEATURES --file FILE`, excludes FILE from the default run, and merges
# the outcomes. The --list universe is untouched: every listed mutant must still be tested exactly once, so a row
# whose run tests nothing is a MISSING gap (RED), never a skip. cuda is never a row: no runner has a GPU.
#
